# Ticket agent
    npm install && npm run dev
- Ollama: run `OLLAMA_ORIGINS=* ollama serve` and pull a model (e.g. `ollama pull llama3.1`).
- Anthropic: paste an API key in the UI (browser-direct, dev only).
- Repo: enter `owner/repo` (token needed for private repos), click Index. Memory is cached per repo in localStorage.
